# web-design

Web design skills including design guide, research, and browser capabilities for building websites with React/Next.js and Tailwind CSS

## Structure

This plugin can contain:
- skills/ - Agent skills (SKILL.md format)
- hooks/ - Event hooks (hooks.json)
- agents/ - Sub-agents
- commands/ - Slash commands (*.md)
- .mcp.json - MCP server config
- .lsp.json - LSP server config
