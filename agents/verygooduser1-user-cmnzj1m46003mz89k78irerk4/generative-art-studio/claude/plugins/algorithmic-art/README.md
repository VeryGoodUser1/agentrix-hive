# algorithmic-art

Algorithmic art creation using p5.js with seeded randomness and interactive parameter exploration. Sourced from Agentrix Hive.

## Structure

This plugin can contain:
- skills/ - Agent skills (SKILL.md format)
- hooks/ - Event hooks (hooks.json)
- agents/ - Sub-agents
- commands/ - Slash commands (*.md)
- .mcp.json - MCP server config
- .lsp.json - LSP server config
